# Security Policy

## Supported Versions

Currently, only the latest release of PomoFlow is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| > 1.0.x | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in PomoFlow, please report it privately to the maintainers:
1. Open a **Draft Security Advisory** in GitHub under the "Security" tab of this repository.
2. Provide details about the vulnerability, the steps to reproduce it, and any potential mitigation strategies.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If a vulnerability is confirmed, we will issue a patch in a timely manner.
